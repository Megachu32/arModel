Petunjuk Penggunaan WebAR

1
Load Model GLB Custom

Klik tab "Model GLB", pilih atau tarik file .glb / .gltf Anda ke area drop. Model akan langsung dirender 3D.

2
Kamera AR Langsung di Browser (Webcam / HP)

Klik tombol "Nyalakan Kamera Browser" di tab AR. Model 3D akan melayang di atas kamera Anda secara real-time. Anda bisa memutar, memperbesar, dan mengambil foto.

3
Google WebXR Native AR (Spasial)

Klik tombol "Lihat di Ruangan (AR Google)" di smartphone yang mendukung Google ARCore / WebXR untuk menempatkan objek langsung di lantai atau meja ruangan Anda.
